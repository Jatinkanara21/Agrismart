# Contributing to AgriSmart

1. Create a feature branch.
2. Keep Flutter, Laravel, and ML responsibilities separated.
3. Never commit secrets or production credentials.
4. Run the relevant formatters, analyzers, tests, and smoke tests before opening a PR.
5. Use Conventional Commit style messages such as `feat:`, `fix:`, `ci:`, and `docs:`.
6. Document externally required services and model dependencies.
